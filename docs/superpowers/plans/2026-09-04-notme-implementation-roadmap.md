# NotMe MVP 구현 로드맵

**Spec:** `docs/superpowers/specs/2026-09-04-notme-mvp-design.md`

세 게임은 독립적으로 검토하고 배포할 수 있는 하위 시스템이므로 다음 계획을 순서대로 실행한다.

1. `2026-09-04-notme-foundation-plan.md` — React/Vite 앱 셸, 웜 다크 홈, 라우팅, 임시 복구, PWA 기반
2. `2026-09-04-notme-stopwatch-plan.md` — 스톱워치 규칙, 상태 머신, 화면, 동점 재대결
3. `2026-09-04-notme-ladder-plan.md` — 사다리 생성·추적, 설정, SVG 애니메이션, 결과
4. `2026-09-04-notme-marble-plan.md` — MIT 고지, Box2D 엔진, 긴 코스, 카메라·미니맵·스킬·배속, 설정과 결과
5. `2026-09-04-notme-release-plan.md` — 게임 간 통합, 100구슬 성능 검증, 오프라인·설치 검증, Vercel 직접 배포 준비

각 계획은 앞 계획의 공개 인터페이스만 사용한다. 한 계획을 완료하고 테스트와 리뷰를 통과한 뒤 다음 계획으로 이동한다.

## 설계 요구사항 추적

| 설계 영역 | 구현 계획 |
| --- | --- |
| 제품 원칙, 공통 화면, 데이터 수명 | 앱 기반 계획 Task 2~4, 통합 계획 Task 2 |
| PWA, 오프라인, Vercel 직접 배포 준비 | 앱 기반 계획 Task 5, 통합 계획 Task 4~5 |
| 스톱워치 규칙과 백그라운드 처리 | 스톱워치 계획 Task 1~4 |
| 사다리 설정, 생성, 공개 | 사다리 계획 Task 1~4 |
| MIT 고지와 룰렛 설정 | 마블 룰렛 계획 Task 1~2 |
| Box2D, 긴 코스, 카메라, 미니맵, 스킬, 배속 | 마블 룰렛 계획 Task 3~7 |
| 룰렛 결과, 복구, 오류 | 마블 룰렛 계획 Task 8 |
| 100구슬 성능과 전체 완료 기준 | 통합 계획 Task 2~3, Task 6 |
