# 마블 룰렛 코스 긴장감 개선 설계

## 목표

한 가지 코스만 유지하면서 lazygyu/roulette의 첫 번째 맵이 주는 진행 리듬을 참고해, 초반부터 골인 직전까지 순위가 계속 바뀌는 마블 룰렛을 만든다. 특히 전체 폭 바닥에 닿으면 끝나는 현재 골인을 중앙의 좁은 깔때기 배출구로 바꾸고, 스킬을 켰을 때 실제 발동과 시각 효과를 사용자가 알아볼 수 있게 한다.

## 현재 문제와 근거

- 현재 코스는 120 높이에 정적 선 12개, 큰 원형 핀 9개, 회전봉 2개뿐이다. 구간별 상호작용 종류와 회전 방향 변화가 적어 구슬이 비교적 곧게 내려간다.
- 현재 골인 센서는 `x=0..26` 전체 폭이다. 구슬이 마지막 y 좌표를 통과하는 순간 바로 제거되어 참고 맵의 중앙 깔때기와 마지막 회전 게이트에서 생기는 순위 변화가 없다.
- 현재 스킬은 활성 구슬마다 5초에 한 번 2%를 추첨한다. 약 6초인 짧은 레이스에서 2구슬 중 하나라도 발동할 확률은 약 4%이며, 충격파 렌더링도 없어 물리 충격이 발생해도 알아보기 어렵다.
- 참고 맵의 핵심은 좌우로 굽는 외곽 경로, 작은 핀의 밀도 변화, 서로 반대 방향으로 도는 여러 회전봉, 갈라졌다 합쳐지는 통로, 중앙으로 좁아지는 마지막 벽과 목 부분의 회전봉이다. 광고판과 여러 맵 선택, 수명형 장애물은 이번 범위에 포함하지 않는다.

## 선택한 접근

참고 맵의 좌표와 엔티티 형식을 그대로 이식하지 않고, 현재 엔진이 이미 지원하는 `line`, `circle`, `spinner`만으로 동일한 경기 리듬을 구성한다.

직접 이식은 box/polyline/restitution/lifetime 타입을 새로 추가해야 하고 광고 공간이나 기존 맵 전용 여백까지 따라오므로 범위가 커진다. 현재 맵에 회전봉만 추가하는 방법은 골인과 구간 리듬이 단조로운 근본 원인을 남긴다. 따라서 현재 타입을 유지한 단일 코스 재구성이 가장 작고 검증 가능한 방법이다.

## 코스 구조

코스 너비, 전체 높이와 카메라 viewport 높이는 각각 26, 120, 24를 유지한다.

1. **분산 램프**: 좌우에서 번갈아 들어오는 경사로가 시작 무리를 나눈다. 출발 구슬이 장애물 위에 생성되거나 10초 이상 첫 구간에 머물지 않아야 한다.
2. **핀 필드**: 큰 원 몇 개 대신 작은 핀을 엇갈린 행으로 배치한다. 모든 길을 막는 수평 장벽은 만들지 않는다.
3. **회전 교차 구간**: 짧은 회전봉을 여러 높이에 나눠 배치하고 인접한 회전봉의 방향을 번갈아 설정한다. 전체 코스에는 최소 5개의 회전봉이 있어야 한다.
4. **분기·재합류 구간**: 선형 레일로 좌우 경로를 만들고 중앙 장애물로 구슬을 나눈 뒤 다시 합친다. 의미 없이 고립된 큰 원형 구조물은 두지 않는다.
5. **깔때기 골인**: 좌우 경사벽이 중앙 통로로 좁아지고 목 부분에 마지막 회전봉을 둔다. 목 아래에는 구슬 지름보다 충분히 넓고 전체 코스보다 훨씬 좁은 수직 배출구가 이어진다. 골인 센서는 이 배출구 폭에만 존재하며, 외곽 바닥을 통과한 구슬은 골인으로 인정하지 않는다.

골인 순위는 중앙 센서를 실제로 교차한 순서만 사용한다. 이탈한 구슬은 기존처럼 확정된 출발 위치로 복귀하며, 3초 정체 해소 규칙은 유지한다.

## 스킬 규칙

- 스킬이 켜져 있으면 6~8초의 시뮬레이션 시간 사이의 무작위 간격마다 활성 구슬 중 하나를 동일 확률로 선택한다. 4배속은 물리와 함께 이 시간도 빠르게 흐르지만 한 판에서 효과가 과도하게 연속되지 않아야 한다.
- 선택된 구슬을 중심으로 기존 `impact` 물리를 한 번 적용한다. 참가자나 구슬 개수에 따른 가중치는 없다.
- 발동 간격과 대상 선택은 주입된 난수원을 사용해 같은 seed에서 재현 가능해야 한다.
- 스킬이 꺼져 있으면 간격 계산, 대상 추첨, 충격과 시각 효과가 모두 발생하지 않는다.
- 완주하거나 제거된 구슬은 대상에서 제외한다. 활성 구슬이 없으면 발동하지 않는다.
- 한 판에서 사용자가 체감할 수 있는 1~3회 정도를 목표로 하되, 레이스 길이에 따라 자연스럽게 달라질 수 있다.

## 충격파 표시

스킬 발동 위치에 500ms 동안 커지는 원형 충격파를 표시한다. 시작 반경은 구슬 주변, 마지막 반경은 약 5 월드 단위이며 시간이 지날수록 투명해진다. 효과는 물리 판정과 분리된 snapshot 데이터로 Canvas와 미니맵이 같은 프레임에 읽는다. 결과 화면에는 지난 효과를 복원하지 않는다.

색상은 기존 웜 다크를 유지한다.

- 배경: `#211b18`
- 코스 레일: `#efd5ae`
- 회전봉·골인: `#ef8d6f`
- 스킬 충격파: `#7dd3fc`

레이아웃과 글꼴은 변경하지 않는다. 시각적 주인공은 마지막 깔때기와 회전 게이트이며, 추가 장식이나 새 카드 UI는 만들지 않는다.

## 데이터와 구현 경계

- `course.ts`: 단일 코스 좌표, 좁은 골인 센서 검증, 회전봉 고유 ID와 경계 검증.
- `SkillSystem.ts`: 전역 발동 간격과 균등 대상 선택. 발동한 구슬 ID를 엔진에 반환한다.
- `RouletteEngine.ts`: 발동 위치를 효과 snapshot으로 생성하고 500ms 수명을 관리한다.
- `types.ts`: 필요한 효과 snapshot 타입만 추가한다.
- `CanvasRenderer.ts`: 메인 Canvas와 미니맵에 확장·감쇠 원을 렌더한다.
- `Box2dPhysics.ts`: 기존 균등 충격 물리를 유지한다. 실제 효과 크기가 부족한지는 통합 테스트와 시각 확인으로 판단하며 근거 없이 힘을 조정하지 않는다.

## 검증 기준

- 코스 검증이 좁고 유효한 중앙 골인 센서를 허용하고 0폭·범위 밖 센서를 거부한다.
- 최소 5개 회전봉, 양방향 각속도, 작은 핀 필드, 중앙 깔때기와 수직 배출구가 데이터 테스트로 고정된다.
- 골인 센서 바깥으로 내려간 구슬은 순위에 들어가지 않고, 중앙 센서 교차만 순위를 확정한다.
- 결정적 난수로 스킬 발동 시점·대상·비활성 상태를 단위 테스트한다.
- 실제 Box2D에서 `impact` 뒤 주변 구슬이 발동 구슬로부터 밀려나는지 검사한다. 기존 힘으로 확인되면 충격 상수는 바꾸지 않는다.
- 충격파 반경과 투명도 렌더링을 Canvas 테스트로 검증한다.
- 실제 Box2D에서 스킬 on/off 모두 100구슬과 기존 seed가 완주하고 순위가 재현된다.
- 모바일·데스크톱 브라우저에서 100구슬이 60초 안에 완주하고 frame p95가 32ms 이하다.
- 모바일 실행 스크린샷에서 코스 구간의 반복감, 마지막 깔때기, 회전 게이트와 스킬 충격파를 직접 확인한다.

## 제외 범위

- 여러 맵 선택
- 녹화, 광고, 예상 순위, 특정 순위 선택
- 구슬별 무게나 스킬 가중치
- 참고 저장소의 지도 데이터를 그대로 복제하는 범용 map importer
- 자동 슬로모션과 별도 결과 애니메이션
