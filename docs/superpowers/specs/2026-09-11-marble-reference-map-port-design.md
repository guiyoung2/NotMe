# 마블 룰렛 참고 맵 직접 이식 설계

## 목적

기존 NotMe 마블 코스의 부분 좌표 조정을 중단하고 `lazygyu/roulette`의 첫 번째 맵 `Wheel of fortune`을 NotMe 물리 형식으로 직접 이식한다. 참가자 설정, 구슬별 이름·색상, 스킬, 배속, 순위, 결과, 다시 하기는 유지하고 코스 데이터만 교체한다.

## 현재 문제

- 현재 하단 y=76~120은 폭 20의 빈 직선 통로여서 대부분 자유낙하한다.
- 최종 통로 폭만 1.2로 줄였기 때문에 사용자가 보는 결승 진입부는 여전히 넓다.
- 기존 장애물은 참고 맵의 연속 벽과 관계없이 배치되어 충돌을 피하는 경로가 많다.
- 좌표 테스트와 완주 여부만 확인해 화면에서 보이는 입구 폭과 체감 속도를 검증하지 못했다.

## 선택한 접근

참고 맵 첫 스테이지의 좌표를 NotMe의 기존 장애물 타입으로 직접 표현한다. 참고 맵의 주요 x 범위가 1.25~24이고 NotMe 코스 폭이 26이므로 별도 확대·축소 없이 같은 좌표를 사용한다. y<0인 시작 벽만 y=0에서 잘라내고, 참고 맵의 골인선 y=111에 맞춰 마지막 세로벽을 종료한다.

중력은 두 구현 모두 `(0, 10)`이므로 변경하지 않는다. 레이스 시간을 늘리기 위해 중력을 낮추거나 인위적인 지연 시간을 추가하지 않는다.

## 코스 구조

### 외곽 안전벽

NotMe의 x=0, x=26 안전벽은 구슬 이탈 방지용으로 유지한다. 실제 이동 경로는 아래의 연속 내부벽 두 개가 결정한다.

### 왼쪽 이동벽

```text
(9.25,0) → (9.25,8.5) → (2,19.25) → (2,26)
→ (9.75,30) → (9.75,33.5) → (1.25,41) → (1.25,53.75)
→ (8.25,58.75) → (8.25,63) → (9.25,64) → (8.25,65)
→ (8.25,99.25) → (15.1,106.75) → (15.1,111)
```

### 오른쪽 이동벽

```text
(16.5,0) → (16.5,9.25) → (9.5,20) → (9.5,22.5)
→ (17.5,26) → (17.5,33.5) → (24,38.5) → (19,45.5)
→ (19,55.5) → (24,59.25) → (24,63) → (23,64)
→ (24,65) → (24,100.5) → (16,106.75) → (16,111)
```

두 벽은 참고 맵처럼 좌우로 이동 경로를 번갈아 꺾으며, y=65 이후에는 x=8.25~24 내부에서만 구슬이 움직이게 한다.

## 내부 구조물

참고 맵의 두 폐쇄형 내부 구조물을 일반 `line` 연속 선분으로 그대로 구성한다.

- 사각 경로: `(12.75,37.5) → (7,43.5) → (7,49.75) → (12.75,53.75) → (12.75,37.5)`
- 삼각 경로: `(14.75,37.5) → (14.75,43) → (17.5,40.25) → (14.75,37.5)`

## 정적 장애물

- y=28, 30, 32에 x=12.5와 15.5의 0.2×0.2 마름모 6개를 둔다.
- y=66.6에 x=9.4부터 22.7까지 참고 좌표의 0.6×0.1 막대 8개를 +45도로 둔다.
- y=69.1에 같은 x 좌표의 막대 8개를 -45도로 둔다.
- y=92, 95, 98에 참고 좌표의 0.25×0.25 마름모 14개를 둔다.
- 참고 맵에 없는 기존 원형·큰 사각 범퍼·하단 회전봉은 제거한다.

## 회전봉

참고 맵의 회전봉 6개만 사용한다.

```text
(8,75)   length 2, angularVelocity +3.5
(12,75)  length 2, angularVelocity -3.5
(16,75)  length 2, angularVelocity +3.5
(20,75)  length 2, angularVelocity -3.5
(24,75)  length 2, angularVelocity +3.5
(14,106.75) length 2, angularVelocity -1.2
```

y=75의 다섯 막대는 참고 소스의 간격과 회전 방향을 그대로 따른다. 결승 회전봉은 좁은 입구 바로 왼쪽에서 반시계 방향으로 회전한다.

## 결승 입구

- 깔때기 시작: 왼쪽 `(8.25,99.25)`, 오른쪽 `(24,100.5)`.
- 좁은 입구: x=15.1~16, y=106.75, 폭 `0.9`.
- 세로 골인 통로: x=15.1~16, y=106.75~111.
- 골인 센서: `(15.1,111) → (16,111)`.
- 구슬 지름은 0.5이므로 입구는 구슬 지름의 1.8배이며 한꺼번에 통과하기 어렵다.
- 길이 2의 결승 회전봉은 x=13~15를 회전하며 입구의 왼쪽 끝을 반복해서 막는다.
- 좁은 입구와 결승 회전봉은 물리·시각 설계다. 완료 판정은 참고 구현처럼 코스 안에서 구슬이 y=111을 처음 넘는지로 결정하며, 골인 센서 폭은 완료 판정 필터가 아니다.

## 코드 변경 범위

## 검증 기준

사용자의 최소 검증 요청을 지킨다.

1. 구조 테스트 RED 1회, GREEN 1회.
2. 고정 시드 100구슬 완주 테스트 1회.
3. 로컬 실제 레이스 1회에서 다음만 확인한다.
   - 미니맵의 전체 경로가 참고 맵과 같은 굴곡을 가진다.
   - 넓은 자유낙하 구간 없이 구슬이 벽·정적 장애물·회전봉과 반복 충돌한다.
   - 결승 입구가 폭 0.9로 보이고 구슬이 회전봉 앞에 잠시 모인다.
4. production build 1회.
5. 실패가 없으면 반복 테스트, 다중 시드, 복수 브라우저 검증은 하지 않는다.

## 완료 조건

- 현재 NotMe의 커스텀 코스 형상이 남지 않는다.
- 참고 맵 첫 스테이지의 두 연속 벽, 두 내부 구조물, 정적 장애물, 회전봉 배치가 반영된다.
- 결승 입구의 실제 물리 폭과 렌더링 폭이 모두 0.9이다.
- 결승 회전봉이 입구 바로 왼쪽에서 반시계 방향으로 작동한다.
- 자유낙하 위주의 현재 레이스보다 충돌과 정체가 명확히 늘어난다.
- 기존 게임 UI와 설정 기능은 그대로 동작한다.
